GarlicTransfer

Guided console-to-PC and PC-to-console save transfers using local or volunteer PPR oracles.

Client console

Discover a PS5 on firmware 14.22 to check pairing.

Experimental Windows pairing, not yet verified on a live PS5: start here, then on the PS5 open Settings → System → System Software → Data Transfer and select “GarlicTransfer Pairing.” “Can’t transfer data” is expected. If the app confirms pairing, return to the home screen and browse saves. The captured identifier stays on this PC.

The verified first browse used a decimal PSN account ID. Enter it above, or read it from a PS4 USB backup; the USB picker has not been live-tested end to end. After a prior browse, local metadata supplies the ID automatically. It is not a PSN password.

Upload destination

Select user/save(s), then on the console go to Settings → System → System Software → Data Transfer, press Continue, select “GarlicTransfer” from the found consoles, then select “Start transfer”. Delete ALL selected original saves before upload.

Ready. Browse the console, then choose which saves to download or upload.
