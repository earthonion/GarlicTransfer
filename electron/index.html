Choose one way to link the selected console. Console pairing saves a reusable 32-byte approval identifier on this PC. The USB and manual methods use your decimal PSN account ID (also called UID). Neither is your PSN password.

Pair from PS5 experimental

Start pairing here. On the PS5, open Settings → System → System Software → Data Transfer, press Continue, then select “GarlicTransfer Pairing.” A “Can’t transfer data” message is expected. Return to the PS5 home screen after this app confirms the link.

How to browse console saves

Discover and select your PS5, then link it above if prompted. Leave it on the home screen and choose Browse console saves. When the PS5 requests it, briefly press its physical power button until it beeps, then release. After the save list appears, choose what to download and finish the session.

How to upload saves

Choose Upload selected saves, select the destination user and a downloaded save, then follow Upload destination below. A source save folder must be a GarlicTransfer download in its original format; a standalone file cannot be uploaded.

Upload destination

Select the destination user and save. Keep a backup, then delete the matching save from console storage to avoid a conflict. On the PS5, open Settings → System → System Software → Data Transfer, press Continue, select “GarlicTransfer,” then select “Start transfer.”

Use a save downloaded by GarlicTransfer, or choose one from this console profile below. Arbitrary files are not supported.
